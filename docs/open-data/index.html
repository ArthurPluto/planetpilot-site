Open data

Planet Pilot's cities, roads, parks and waters are built from OpenStreetMap. The databases we derived from it are yours to download and reuse under the same open licence.

Last updated: October 7, 2026

What this is

Planet Pilot's world is drawn from open map data. The game itself is proprietary, but the map databases derived from OpenStreetMap (through the Overture Maps Foundation releases) are covered by the Open Database License (ODbL) 1.0, so we offer them here, under the same licence, together with the scripts that build them.

Map data © OpenStreetMap contributors, ODbL 1.0; Overture Maps Foundation. Building footprints also from Microsoft, Esri Community Maps contributors and Google (CC BY 4.0), via Overture Maps.

The game world shown on screen is a Produced Work under the ODbL; only the databases below are Derivative Databases.

Downloads

  • All databases, this game releaseDownload ZIP
    One ZIP per game release (planetpilot-odbl-v<version>.zip, about 200 MB): every file in the table below, ODBL_LICENSE.txt, ODBL_SOURCES.txt and a short README describing the binary formats. Each release's ZIP stays available for at least as long as that game version is sold.
  • The bake scriptsOpen the repository
    The scripts named below, as they were at that release. They need Python 3.12, numpy and the Overture release from s3://overturemaps-us-west-2/release/<release id>/. Together they describe the methods that rebuild every database.
  • The two CC BY-SA modelsOpen the repository
    The 3D models of Christ the Redeemer and Mount Rushmore are adapted from CC BY-SA 3.0 photos and are offered under CC BY-SA 3.0 (christ_redeemer.glb, mount_rushmore.glb, with the notice from licenses/CC_BY_SA_MODELS.txt).

The derived databases

All of them sit in one folder of the game, data/world/odbl/ (packed inside the game files), except one lake patch.

FileWhat it isSource releaseBuilt by
roads.binCity main roads (motorway to secondary, named avenues) and street bearingsOverture transportation/segment 2026-09-23.1tools/bake_roads.py
roadgraph.binThe same roads as a connected graphOverture transportation/segment 2026-09-23.1tools/bake_road_graph.py
roadprof/*.binRoad profiles (deck heights, bridges, viaducts, tunnels) of every graph edge, solved on the game terrainDerived from roadgraph.bintools/bake_road_profiles.gd (tools/bake_road_profiles_par.py)
buildings/*.bin (one per city), city_towers.jsonBuilding footprints and heightsOverture buildings 2026-09-23.1 (heights also from 3D-GloBFP, Google Open Buildings 2.5D Temporal and GHSL, CC BY 4.0)tools/fetch_heights.py fetch, tools/bake_city_buildings.py
green/*.bin (one per city)Parks, gardens, grass, woods, cemeteries, treesOverture base land_use and land 2026-09-23.1tools/bake_city_green.py
city_water.binReal-width city rivers and docksOverture base.water 2026-09-23.0tools/bake_city_water.py
coast_ov_osm.binCoast patches (piers, docks)Overture base.water 2026-09-23.0tools/bake_city_water.py
data/world/lakes.bin record 10 and the lake_field.bin tiles round itThe Lake Ontario shore (one OSM feature patched into the Natural Earth lakes)Overture base.water 2026-09-23.0tools/patch_lake_osm.py, then tools/bake_lake_field.py --lakes 10

The game also ships data/landmarks/real.json (positions and footprint boxes of fewer than 100 landmarks from OpenStreetMap via Overpass, and Wikidata, CC0). That is an insubstantial extract under the OSMF Substantial guideline; we credit it and include it in the download anyway.

licenses/ODBL_SOURCES.txt next to the game lists each file, its source release and the command that rebuilt it, as shipped.
